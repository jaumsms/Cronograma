📊 Data Engineer Roadmap Tracker

Este projeto é uma aplicação web interativa para acompanhar a evolução na jornada de Analista de Dados para Engenheiro de Dados.

🌐 Acesse o projeto

👉 https://jaumsms.github.io/Cronograma/

🚀 Funcionalidades

- Marcar progresso dos estudos
- Visualizar evolução por fases
- Interface interativa e responsiva
- Salvamento automático no navegador

🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- GitHub Pages

🎯 Objetivo do projeto

Este projeto foi desenvolvido para simular um sistema de acompanhamento de aprendizado em engenharia de dados, permitindo visualizar progresso e organização dos estudos.

📌 Próximos passos (em desenvolvimento)

- Integração com backend
- Armazenamento em banco de dados
- Dashboard de métricas
